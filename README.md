# 최광빈

### HR 업무의 불편을 찾아 개선 도구를 만듭니다

HR 직무를 준비하는 최광빈입니다. 카카오모빌리티 행성지원팀에서 경험한 HR·자회사 관리 업무를 바탕으로, 반복되는 자료 취합과 점검 절차를 개선했습니다.

직접 문제와 요구사항을 정하고, AI와 함께 구현한 뒤 사용·검증하며 다듬었습니다.

**[HR 업무 개선 사례 보기 →](https://poby-ya.github.io/hr-automation-portfolio/)** · [자동화 과정 자세히 보기](https://poby-ya.github.io/hr-automation-portfolio/#automation)

## 먼저 보시면 좋은 작업

### HR·자회사 관리 업무 자동화

매달 들어오는 인력 자료, 흩어진 규정과 의사록, 반복되는 주간 보고를 다뤘습니다. 자료를 모으는 과정에 점검과 알림을 연결하고, 담당자가 필요한 화면을 한곳에서 찾도록 구성했습니다.

[![HR 통합 대시보드 미리보기 — 실제 업무 경험을 예시 데이터로 재현](https://raw.githubusercontent.com/Poby-ya/hr-automation-portfolio/main/docs/hr-dashboard.png)](https://poby-ya.github.io/hr-automation-portfolio/#dashboard)

*실제 업무 경험을 바탕으로 만든 재현본입니다. 화면의 이름·법인·숫자는 예시입니다.*

- **업무를 이해하고 기준 정하기:** 무엇을 모을지뿐 아니라, 값이 다를 때 어디를 확인해야 하는지 정의했습니다.
- **반복되는 절차 개선하기:** 입력 이후 점검·취합·알림으로 이어지는 흐름을 만들었습니다.
- **운영과 인수인계까지 살피기:** 권한 요청, 수정 요청, 사용 안내와 남은 한계를 함께 정리했습니다.

[대시보드 직접 보기](https://poby-ya.github.io/hr-automation-portfolio/#dashboard) · [프로젝트 설명 읽기](https://github.com/Poby-ya/hr-automation-portfolio/blob/main/README.md)

## 직접 만든 도구들

일상에서 느낀 불편도 도구로 만들어 사용하며 개선하고 있습니다.

### 영어 읽기 코치

영어 글을 읽다 막힌 부분을 확인하고 다시 복습할 수 있도록, 문장 해설과 단어·문장 복습을 연결했습니다.

[설정 없이 샘플 보기](https://poby-ya.github.io/reading-coach/#/read/sample-paper-mars) · [설명 읽기](https://github.com/Poby-ya/reading-coach/blob/main/README.md)

### KU 작업실

고려대 AI Gateway를 한국어 채팅 화면에서 사용할 수 있도록, 폴더·파일 선택과 작업 모드를 구성했습니다.

[화면과 설명 보기](https://github.com/Poby-ya/ku-workspace-releases/blob/main/README.md)

### PDF 필기

PDF를 읽으면서 메모하고 그림을 정리할 수 있도록, 필기와 노트 기능을 담았습니다.

[기능과 사용 안내 보기](https://github.com/Poby-ya/pdf-notes-mac-updates/blob/main/README.md)

## AI와 함께 만드는 방식

불편한 작업을 관찰하고 → 입력·결과·예외 상황을 정하고 → AI와 구현하고 → 직접 확인하며 고칩니다.

HR 자동화는 실무 경험을 바탕으로 한 사례이며, 나머지 도구는 개인 제작 프로젝트입니다. 각 프로젝트에서 확인할 수 있는 화면과 사용 조건을 함께 안내합니다.
